ModelsRun these

Open models that fit a single lab GPU. Click a card to read its model card on Hugging Face; pull it with Ollama or serve it per the modules. Always check the license on the card.

Qwen3-8B Apache 2.0

The safe default — open, ungated, fast on one GPU.

Google Gemma Apache 2.0

Smaller instruct variants fit comfortably. Verify the current version.

gpt-oss-20b Apache 2.0

Open model that ships quantized to about 16 GB.

DeepSeek-R1-Distill-Qwen-7B

A reasoning model that fits one GPU. Check the card's license.

DeepSeek-R1-Distill-Llama-8B

The Llama-based reasoning distill. Check the card's license.
